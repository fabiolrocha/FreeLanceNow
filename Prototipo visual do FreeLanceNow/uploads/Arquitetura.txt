INTRODUÇÃO
Finalidade
Este documento fornece uma visão arquitetural abrangente do sistema FreeLanceNow, usando diversas visões de arquitetura para representar diferentes aspectos do sistema. O objetivo deste documento é capturar e comunicar as decisões arquiteturais significativas que foram tomadas em relação ao sistema.
O documento irá adotar uma estrutura baseada na visão “4+1” de modelo de arquitetura [KRU41]. 

Figura 1 – Arquitetura 4+1

Escopo
Este Documento de Arquitetura de Software se aplica ao FreeLanceNow, uma plataforma digital (web e mobile) voltada para conectar pessoas que precisam de serviços gerais com profissionais freelancers que oferecem esses serviços. A plataforma será desenvolvida pela Equipe FreeLance no âmbito do projeto acadêmico da disciplina de Engenharia de Software.
O sistema contempla cadastro e autenticação de usuários, cadastro de serviços por freelancers, busca e contratação de serviços por clientes, avaliação dos serviços realizados e um painel administrativo para gerenciamento da plataforma.
Definições, Acrônimos e Abreviações
QoS – Quality of Service, ou qualidade de serviço. Termo utilizado para descrever um conjunto de qualidades que descrevem os requisitos não-funcionais de um sistema, como performance, disponibilidade e escalabilidade [QOS].
LGPD – Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018), que regulamenta o tratamento de dados pessoais no Brasil.
UML – Unified Modeling Language, linguagem gráfica de notação padrão para modelagem de sistemas orientados a objetos.
REST – Representational State Transfer, estilo arquitetural para sistemas distribuídos baseado em recursos acessíveis por HTTP.
JWT – JSON Web Token, padrão aberto (RFC 7519) para autenticação e troca segura de informações entre partes.
ORM – Object-Relational Mapping, técnica que mapeia estruturas de um banco de dados relacional para objetos no código da aplicação.
2FA – Two-Factor Authentication, autenticação de dois fatores utilizada como camada adicional de segurança no login.
MDS – Metodologia de Desenvolvimento de Software, conjunto de práticas e artefatos adotados pela equipe.
JDBC – Java Database Connectivity, API padrão da plataforma Java para acesso a bancos de dados relacionais.

REQUISITOS E RESTRIÇÕES ARQUITETURAIS
Esta seção descrever os requisitos de software e restrições que tem um impacto significante na arquitetura. 

Requisito
Solução
Linguagem
Back-end em Java (Spring Boot / Spring MVC) para implementação da API REST e das regras de negócio. Front-end web em HTML5, JavaScript (ES6+) e Tailwind CSS, com layout responsivo para acesso via desktop e dispositivos móveis no mesmo código-base.
Plataforma
Servidor de aplicação Java (JRE 17+) com Spring Boot utilizando Tomcat embarcado, executado em ambiente Linux, com possibilidade de containerização via Docker. Servidor web Nginx atuando como reverse proxy para a API e servindo os arquivos estáticos do front-end.
Segurança
Autenticação via JWT (JSON Web Token) com opção de 2FA. Senhas armazenadas com hash bcrypt. Comunicação exclusivamente via HTTPS (TLS 1.2+). Controle de acesso baseado em perfis (Cliente, Freelancer e Administrador). Conformidade com a LGPD para tratamento de dados pessoais.
Persistência
Banco de dados relacional PostgreSQL 15 para armazenamento de usuários, serviços, contratações e avaliações. Armazenamento de imagens em serviço de object storage (S3-compatible). Acesso aos dados via ORM para abstração das consultas.
Internacionalização (i18n)
Interface disponibilizada inicialmente em Português do Brasil (pt-BR). Estrutura preparada com chaves de tradução para adição futura de outros idiomas sem necessidade de refatoração.

VISÃO DE IMPLANTAÇÃO
O sistema será implantado na seguinte topologia:
•	Dispositivo do Usuário: computador com navegador web moderno (Chrome, Firefox, Edge ou Safari) ou smartphone iOS/Android acessando a aplicação através do navegador móvel, com layout responsivo adaptado ao tamanho da tela.
•	Servidor de Aplicação: instância Linux executando a API FreeLanceNow (Java com Spring Boot, Tomcat embarcado) e servindo os arquivos estáticos do front-end web (JavaScript + Tailwind CSS), com Nginx como reverse proxy.
•	Servidor de Banco de Dados: instância dedicada com PostgreSQL 15, acessível via JDBC apenas pela rede interna do servidor de aplicação (porta 5432).
•	Serviços Externos: provedor SMTP para envio de e-mails transacionais, serviço de notificação para alertas em tempo real ao usuário e serviço de object storage para armazenamento das imagens dos serviços.

QUALIDADE

Enumerar os itens de qualidade de software [QOS] significativos para a aplicação:

Item
Descrição
Solução
Escalabilidade
Capacidade do sistema de suportar crescimento da base de usuários sem refatoração completa da arquitetura.
Arquitetura em camadas com separação entre front-end e back-end (API REST). Possibilidade de escalar horizontalmente a API atrás de um balanceador de carga e de adicionar réplicas de leitura no PostgreSQL.
Confiabilidade, Disponibilidade
Garantia de que os dados de contratos e avaliações não sejam perdidos e de que o sistema esteja disponível para os usuários.
Backup automático diário do banco de dados PostgreSQL, transações ACID para as operações críticas (contratação, avaliação) e monitoramento de saúde da aplicação.
Portabilidade
Aplicativo responsivo e funcional em iOS, Android e principais navegadores web
Front-end web com layout responsivo utilizando Tailwind CSS (breakpoints para desktop, tablet e mobile). Um único código-base em JavaScript atende todos os dispositivos, eliminando a necessidade de aplicativos nativos nesta versão.
Segurança
Proteção dos dados pessoais dos usuários e das credenciais de acesso, em conformidade com a LGPD.
Autenticação JWT com expiração, 2FA opcional, criptografia de senhas com bcrypt, HTTPS obrigatório em todas as chamadas e aceite explícito de Termos de Uso e Política de Privacidade no cadastro.
Usabilidade
Facilidade de uso para perfis técnicos e não técnicos (Requisito Não-Funcional do Documento de Visão).
Fluxos simplificados de cadastro, busca e contratação com no máximo 3 cliques até a ação principal. Feedback visual imediato para todas as ações do usuário.

PROTÓTIPO
  Principais telas do sistema
Telas
Função
Busca de Serviços
Permitir que empresas ou clientes explorem "pacotes de serviços" específicos previamente cadastrados pelos freelancers na plataforma.
Perfil do Freelancer
Atuar como o currículo detalhado e portfólio digital do profissional. É a página de conversão onde a empresa toma a decisão de enviar um convite de contratação.
Perfil da Empresa
Servir como uma página institucional pública para a empresa contratante. Seu objetivo é transmitir segurança e transparência para o freelancer que avalia uma proposta.
Dashboard da Empresa
Ser o centro de controle e painel gerencial do contratante logado no sistema.
Meus Projetos
Gerenciar o funil de contratação da empresa, organizando as demandas abertas, em andamento e já concluídas.
Publicar Novo Projeto
Interface estruturada de formulário para que a empresa crie e detalhe uma nova oportunidade de trabalho, tornando-a visível para os freelancers da plataforma.
Busca de Profissional
Mecanismo de "Hunting" (pesquisa ativa). Diferente da "Busca de Serviços" (onde se procura um produto fechado), aqui a empresa busca o perfil ideal de talento por meio de habilidades e características.
Tela de Login
Autenticar o usuário de forma segura e redirecioná-lo automaticamente para o painel correto (Dashboard da Empresa ou do Freelancer) com base no seu tipo de conta.
Tela de Cadastro - Perfil Freelancer
Coletar as informações vitais para criar a conta do profissional e prepará-lo para a exibição no catálogo da plataforma.
Tela de Cadastro - Perfil Empresa/Cliente
Registrar a empresa contratante de forma rápida para que ela possa publicar um projeto ou iniciar uma busca o mais rápido possível.
Fluxo de usuário
Visitante acessa a plataforma -> Escolhe "Cadastrar" ou "Entrar" -> Preenche credenciais -> Sistema redireciona com base no Tipo de Conta. 
Fluxo do Cliente: Acessa Home -> Realiza Busca/Filtro -> Visualiza Lista -> Clica em um Serviço -> Analisa Perfil -> Clica em "Solicitar Serviço" -> Preenche Dados -> Envia Solicitação. Após conclusão -> Recebe Notificação -> Avalia o Serviço. 
Fluxo do Freelancer: Acessa Dashboard -> Clica em "Adicionar Serviço" -> Preenche Formulário e Fotos -> Publica. Recebe notificação de solicitação -> Aceita ou Recusa (em até 48h).
