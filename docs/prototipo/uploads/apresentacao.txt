 04 · VISÃO LÓGICA 
 Visão Geral — Pacotes e Camadas 
 Arquitetura em camadas com separação clara de responsabilidades entre apresentação, negócio e dados. 
 Apresentação 
 Front-end web responsivo (HTML5, JS, Tailwind CSS) 
 Controle / API REST 
 Controllers Spring MVC — recebem requisições e orquestram 
 Negócio (Services) 
 Regras de negócio, validações e fluxos da aplicação 
 Persistência / Dados 
 Repositórios via ORM sobre o PostgreSQL 15 
 Fluxo da requisição 
 As requisições descem da camada de apresentação até os dados; 
 cada camada conhece apenas a imediatamente inferior. 
 Organizado em pacotes por domínio: usuários, serviços, contratações e avaliações.

 05 · VISÃO DE IMPLANTAÇÃO 
 Topologia de Implantação 
 Dispositivo do Usuário 
 Navegador web ou smartphone iOS/Android, layout responsivo. 
 › 
 Servidor de Aplicação 
 Linux + Spring Boot/Tomcat e front-end estático, atrás do Nginx. 
 › 
 Servidor de Banco 
 PostgreSQL 15 dedicado, via JDBC pela rede interna (porta 5432). 
 › 
 Serviços Externos 
 SMTP, notificações em tempo real e object storage de imagens. 
 Comunicação exclusivamente via HTTPS (TLS 1.2+) entre cliente e servidor de aplicação.

 07 · ATRIBUTOS DE QUALIDADE 
 Qualidade (QoS) 
 Escalabilidade 
 API escalável horizontalmente atrás de balanceador e réplicas de leitura no PostgreSQL. 
 Confiabilidade 
 Backup diário, transações ACID nas operações críticas e monitoramento de saúde. 
 Portabilidade 
 Layout responsivo (Tailwind) com um único código-base para web e mobile. 
 Segurança 
 JWT com expiração, 2FA, bcrypt, HTTPS e aceite de termos conforme a LGPD. 
 Usabilidade 
 Fluxos simples — até 3 cliques à ação principal — com feedback visual imediato.
